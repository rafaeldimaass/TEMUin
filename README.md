# TEMUin
TEMUin adalah platform web matchmaking tim lomba yang dikembangkan untuk mahasiswa Jurusan Teknologi Informasi, Politeknik Negeri Malang (JTI Polinema). TEMUin membantu mahasiswa menemukan rekan tim lintas bidang keahlian untuk mengikuti berbagai kompetisi — tidak terbatas pada lomba IT saja. Proyek ini dikembangkan sebagai bagian dari mata kuliah Project Based Learning (PBL).
